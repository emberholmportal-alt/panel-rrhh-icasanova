Cargar export de Movimientos

Arrastrá acá el export de Movimientos del reloj (anual o de un período), o elegí el archivo.

Trae, por persona y día, la jornada y el motivo de cada ausencia. Los meses que vengan en el archivo nuevo reemplazan a los cargados antes. El anual tarda cerca de un minuto en leerse.

Conexión con Microsoft 365 · SharePoint

Opcional, para más adelante. Mientras tanto, vacaciones y eventuales se actualizan subiendo el Excel. Con esta conexión se leerían directo del Excel online con tu cuenta de Grupo Gestión (Microsoft Graph, permiso de solo lectura). Para eso hace falta registrar el panel una sola vez en Microsoft Entra ID:

  1. Publicá el panel en una dirección web (https) o abrilo en http://localhost. Microsoft no permite iniciar sesión desde un archivo abierto con doble clic.
  2. En portal.azure.com → Microsoft Entra ID → Registros de aplicaciones → Nuevo registro: nombre "Panel RRHH I.Casanova", cuentas solo de este directorio.
  3. En URI de redirección elegí Aplicación de página única (SPA) y pegá esta dirección:
  4. En Permisos de API agregá Microsoft Graph → Delegados → Files.Read.All (y User.Read, que viene por defecto).
  5. Copiá el Id. de aplicación (cliente) y el Id. de directorio (inquilino) acá abajo y tocá Conectar.
